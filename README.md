# Omarchy dotfiles
This repository contains the dotfiles of my current setup of Omarchy.

## Using the dotfiles
To use the dotfiles, clone the repo with yadm and you should be good to go.

## files
The files in this repo are a mix of a port of present configuration in bash translated to fish, and custom settings.
For example the ~/.config/fish/conf.d/aliases.fish is the same as /usr/share/omarchy/default/bash/aliases
